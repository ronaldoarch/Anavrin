# Anavrim Backend API

API REST para o site Anavrim - Casa de Massagem.

## 🚀 Instalação

```bash
npm install
```

## 🏃‍♂️ Executar

```bash
npm start
```

## 📡 Endpoints

- `GET /api/meninas` - Lista terapeutas
- `POST /api/meninas/:id/foto` - Upload foto
- `PUT /api/meninas/:id` - Editar terapeuta
- `POST /api/banner` - Upload banner
- `POST /api/login` - Login admin

## 🔧 Variáveis de Ambiente

- `PORT` - Porta do servidor (padrão: 3000)

## 🚀 Deploy no Railway

1. Conecte seu repositório
2. Configure a variável `PORT` se necessário
3. Deploy automático!
